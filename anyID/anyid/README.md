# 🔮 anyID - Discover the World Through Your Lens

![anyID Banner](https://via.placeholder.com/1200x400?text=anyID+AI+Powered+Recognition)

> **"What is that?"** — Answered instantly.

**anyID** is your intelligent companion that bridges the gap between the physical and digital worlds. Powered by advanced AI, it identifies objects, plants, animals, and famous personalities from a single photo, offering detailed insights and interactive conversations.

---

## ✨ Features that Wow

*   **📸 Instant Identification**: Snap a photo or upload an image to identify anything from rare plants to vintage cars.
*   **💬 Interactive Chat**: Don't just get a label; *talk* to your discovery! Ask follow-up questions about the identified object.
*   **🆚 Smart Comparison**: Upload two images to see a side-by-side comparison of their features and differences.
*   **📜 History & Favorites**: Keep a personal journal of your discoveries. Never lose track of that cool flower you found.
*   **🌍 Multi-Language Support**: Get results in your native language (English, Spanish, French, Hindi, and more!).

## 🛠️ Getting Started

Ready to explore? Follow these steps to set up **anyID** locally.

### Prerequisites

*   Node.js (v18+)
*   Java JDK 17+
*   Maven

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/anyID.git
cd anyID
```

### 2. Backend Setup (Spring Boot)

Navigate to the backend directory and start the server.

```bash
cd backend
# Configure your Gemini API Key in application.properties first!
mvn spring-boot:run
```

The backend will start on `http://localhost:8080`.

### 3. Frontend Setup (Next.js)

Open a new terminal, navigate to the frontend directory, and blast off! 🚀

```bash
cd anyid
npm install
npm run dev
```

Visit `http://localhost:3000` to start your journey.
