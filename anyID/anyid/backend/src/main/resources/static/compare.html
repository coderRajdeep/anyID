Compare API POST

/api/images/compare

Overview

The Compare API allows users to upload two images side-by-side. The AI analyzes both images to find similarities, differences, and unique features. This is particularly useful for distinguishing between similar-looking plants, animals, or products.

Request Body

Field Type Description
image1Base64* String The first image converted to a Base64 string.
image2Base64* String The second image converted to a Base64 string.

Example Request

{
  "image1Base64": "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
  "image2Base64": "data:image/png;base64/iVBORw0KGgo..."
}

Response

Returns a plain string containing the comparison analysis formatted in Markdown.

Example Response

**Comparison Analysis:**

*   **Image 1:** Shows a Golden Retriever puppy.
*   **Image 2:** Shows a Labrador Retriever puppy.

**Key Differences:**
The Golden Retriever has longer, fluffier fur compared to the short, dense coat of the Labrador. Both appear to be around 8 weeks old...
