Identify API POST

/api/images/identify

Overview

The Identify API is the core of anyID. It accepts an image (Base64 encoded) and uses Google's Gemini AI to identify the main subject of the image. It returns a structured response containing the name, a detailed description, and other relevant details.

Request Body

Field Type Description
imageBase64* String The image file converted to a Base64 string.
category String Optional hint for the AI (e.g., "Plant", "Vehicle").
language String Target language for the description (e.g., "English", "Spanish").

Example Request

{
  "imageBase64": "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
  "category": "Plant",
  "language": "English"
}

Response

Returns a JSON object with the identification results.

Example Response

{
  "name": "Monstera Deliciosa",
  "description": "The Monstera Deliciosa, also known as the Swiss Cheese Plant, is a species of flowering plant native to tropical forests of southern Mexico...",
  "details": "Family: Araceae\nNative: Tropical Americas",
  "searchQuery": "Monstera Deliciosa care"
}
