🚀 API Endpoints

POST /api/images/identify

Analyzes an uploaded image to identify objects, plants, animals, or famous people. Returns detailed information including name, description, and key details.

POST /api/images/compare

Compares two images side-by-side to find similarities and differences. Useful for distinguishing between similar species or objects.

POST /api/images/chat

Enables an interactive chat session based on the context of a previously identified image. Ask follow-up questions to learn more.

🛠️ Technology Stack

This backend service is built using Java Spring Boot, providing a robust and scalable architecture. It leverages the power of Google's Gemini 2.5 Flash model for multimodal analysis, allowing it to "see" and understand images with incredible accuracy.
