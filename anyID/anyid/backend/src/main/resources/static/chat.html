Chat API POST

/api/images/chat

Overview

The Chat API enables a conversational interface. It takes a user's question along with the initial description of an identified object to generate a context-aware response. This makes the AI feel like it "remembers" what it just saw.

Request Body

Field Type Description
message* String The user's follow-up question or comment.
initialDescription* String The description text from the original identification result.

Example Request

{
  "message": "How often should I water it?",
  "initialDescription": "The Monstera Deliciosa is a tropical plant..."
}

Response

Returns a plain string containing the AI's answer.

Example Response

You should water your Monstera Deliciosa every 1-2 weeks, allowing the soil to dry out between waterings. Expect to water more often in brighter light and less often in lower light.
